## What the video teaches

This is the opening section of the course — a pure overview, no code is written. Mike introduces himself and explains what PHP is, what the course will cover, and what you'll be able to do by the end of it. Watch it to get oriented, then move on.

### What PHP is

- PHP is **an awesome programming language** that "you can use on the web."
- It's a great choice when you want to **build an awesome, scalable, and easily maintainable website or web application**.
- PHP **integrates super well with HTML** — the key selling point of the language. "You can actually write your PHP code right along with HTML and they work together perfectly."
- There are **millions of websites and web applications currently online** that use PHP and rely on PHP on the back end.
- PHP is what we call a **server-side language**. It sits on the web server and is able to interact with the client (the browser) and do different things in order to make your website more powerful.

### The course roadmap (exactly as Mike gives it)

Mike lays out the whole course up front. These are the things you're going to learn:

## Key metaphor(s)

- PHP is a language that **"sits on the web server"** — it lives on the server, not in the browser, and interacts with the client to make your website more powerful.
- PHP and HTML "**work together perfectly**" — you can write PHP right alongside your HTML in the same file.

## Why this matters

Before writing a single line of code, understand the division of labor on the web:

- **Client-side** technologies (HTML, CSS, JavaScript) run in the user's browser.
- **Server-side** languages like PHP run on the web server, do the real work (handing files to users, taking input, talking to databases), and send finished HTML back to the browser.

Everything else in this course — the setup, the echo command, variables, forms, loops, classes — builds directly on that single idea.

## Modern note

PHP is still one of the most widely used server-side languages on the web (it powers WordPress, Laravel, Symfony, and countless other systems). The "write PHP right alongside HTML" idea is still exactly how PHP works today on PHP 8.5 — nothing has changed about the core model this video teaches.
