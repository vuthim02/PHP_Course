# Level 5: Modern PHP Ecosystem

**Objective:** Master Composer, PSR standards, Laravel, Symfony, Slim, testing frameworks, and the modern PHP toolchain.

## Chapters

| # | Chapter | Description |

| 5 | Laravel Fundamentals | Installation, routing, controllers, blade |
| 6 | Laravel Eloquent | ORM, relationships, scopes, accessors, mutators |

| 8 | Laravel Testing | PHPUnit, Pest, HTTP tests, browser tests |

| 11 | Symfony Advanced | Doctrine, Messenger, Workflow, Serializer |
| 12 | Slim Framework | Micro-framework for APIs |
| 13 | Testing with PHPUnit | Unit tests, integration tests, mocking |
| 14 | Testing with Pest | Pest PHP, test architecture, custom assertions |
| 15 | TDD (Test-Driven Development) | Red-green-refactor, test design |
| 16 | Mocking and Stubs | Prophecy, Mockery, test doubles |
| 17 | Static Analysis | PHPStan (levels 0-10), Psalm |
| 18 | Code Quality | PHP-CS-Fixer, PHP CodeSniffer, Rector |
| 19 | Profiling and Benchmarking | Blackfire, Xdebug, JMeter |
| 20 | Project: Laravel SaaS App | Complete SaaS with Laravel |
