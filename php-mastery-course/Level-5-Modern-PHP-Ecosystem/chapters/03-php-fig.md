# Chapter 3: PHP-FIG

## Learning Objectives

- Understand PHP-FIG's role in the ecosystem
- Participate in standards development
- Apply FIG-recommended practices

---

## 3.1 PHP-FIG Structure

- **Members**: Major PHP projects and individuals
- **Voting**: Core members vote on PSR acceptance
- **Process**: Draft → Review → Acceptance
- **Current PSRs**: 20+ accepted standards

### Major PSRs by Category:

| Category | Standards |
|----------|-----------|
| Autoloading | PSR-0 (deprecated), PSR-4 |
| Coding Style | PSR-1, PSR-2 (replaced), PSR-12 |
| Interfaces | PSR-3, PSR-6, PSR-7, PSR-11, PSR-13, PSR-14, PSR-15, PSR-18 |

---

## 3.2 Exercises

1. Review the current PHP-FIG voting process
2. Read PSR-12 and reformat a codebase to comply
3. Join the PHP-FIG mailing list
4. Contribute feedback on a draft PSR
