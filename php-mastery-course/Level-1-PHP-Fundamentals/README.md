# Level 1: PHP Fundamentals

**Objective:** Write, run, and debug PHP code. Master syntax, variables, data types, operators, control flow, functions, arrays, strings, forms, and error handling.

## Chapters

| # | Chapter | Description |
|---|---------|-------------|
| 1 | PHP Installation and Configuration | CLI, php.ini, extensions, OPcache |
| 2 | PHP Syntax and Structure | Tags, comments, output, statements |
| 3 | Variables and Data Types | Scalar, compound, special types, type juggling |
| 4 | Constants and Magic Constants | define(), const, predefined constants |
| 5 | Operators | Arithmetic, assignment, comparison, logical, bitwise |
| 6 | Control Flow | if/else, switch, match, ternary, null coalescing |
| 7 | Loops | for, while, do-while, foreach, break, continue |
| 8 | Functions | Declaration, parameters, return, scope, recursion |
| 9 | Built-in Functions | String, array, math, date, file, JSON functions |
| 10 | Arrays | Indexed, associative, multidimensional, array functions |
| 11 | Strings | Heredoc, nowdoc, interpolation, string functions |
| 12 | Numbers and Math | Integers, floats, rounding, random, BC Math |
| 13 | Date and Time | DateTime, timezone, formatting, intervals |
| 14 | Forms and User Input | GET, POST, validation, sanitization |
| 15 | Error Handling | Errors, exceptions, try/catch, custom handlers |
| 16 | File Operations | Reading, writing, uploading, directories, permissions |
| 17 | Includes and Requires | include, require, file organization |
| 18 | Superglobals | $_GET, $_POST, $_SERVER, $_SESSION, $_COOKIE |
| 19 | Knowledge Verification | Quizzes, challenges, projects |
| 20 | Capstone Project | Complete PHP application from scratch |

## Projects

- **Mini:** Calculator, Temperature Converter
- **Intermediate:** Todo List CLI, Notes App
- **Professional:** Contact Form with Validation
- **Enterprise:** User Management System
