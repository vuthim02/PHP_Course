# Level 0 — Recommended Reading & Resources

## Books

| Title | Author | Why |
|-------|--------|-----|
| *Computer Systems: A Programmer's Perspective* | Bryant & O'Hallaron | The definitive book on how hardware and OS work |
| *The Phoenix Project* | Gene Kim | Novel about DevOps — makes IT operations concepts tangible |
| *HTTP: The Definitive Guide* | David Gourley | Everything about HTTP — headers, caching, auth, proxies |
| *Designing Data-Intensive Applications* | Martin Kleppmann | Distributed systems fundamentals — databases, replication, partitions |
| *The Linux Command Line* | William Shotts | Free online — the best Linux CLI introduction |

## Free Online Courses

| Course | Platform | Topic |
|--------|----------|-------|
| *CS50* | edX / Harvard | Computer Science fundamentals |
| *Computer Networking* | Kurose & Ross (YouTube) | TCP/IP, DNS, HTTP deep dive |
| *Linux Basics* | linuxcommand.org | Command line and shell scripting |

## Tools & Setup Guides

- **PHPStorm** — IDE download + free trial: https://www.jetbrains.com/phpstorm/
- **VS Code + PHP Extensions** — Intelephense, PHP Debug, GitLens
- **Docker Desktop** — Run MySQL, Redis, PHP without installing locally
- **Homebrew** (macOS) or **Chocolatey** (Windows) — Package managers
