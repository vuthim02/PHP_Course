# Level 0: Foundations of Web Development and PHP

**Objective:** Understand how computers, networks, the internet, browsers, servers, HTTP, databases, and web applications work before writing a single line of PHP code.

## Chapters

| # | Chapter | Description |
|---|---------|-------------|
| 1 | How Computers Work | CPU, memory, storage, binary, program execution |
| 2 | How Operating Systems Work | Processes, memory management, file systems, Linux |
| 3 | How Networks Work | TCP/IP, OSI model, IP addresses, ports, DNS |
| 4 | How the Internet Works | Infrastructure, routing, data centers, CDNs |
| 5 | How Browsers Work | Rendering pipeline, DOM, CSSOM, storage |
| 6 | How Servers Work | Nginx, Apache, PHP-FPM, request processing |
| 7 | How HTTP Works | Methods, status codes, headers, sessions, REST |
| 8 | How Databases Work | SQL, MySQL, PostgreSQL, indexing, transactions, PDO |
| 9 | How Web Applications Work | MVC, client-server, request lifecycle |
| 10 | Full Request Lifecycle | End-to-end trace from URL to rendered page |
| 11 | Development Environment Setup | PHP, Nginx, MySQL, Docker, Xdebug |
| 12 | Tools of the Trade | Git, Composer, PHPUnit, PHPStan, profiling |
| 13 | Knowledge Verification | Quizzes, challenges, real-world problems |
| 14 | Projects | System Dashboard, Static Site Generator, MVC Framework, SaaS |
| 15 | Career Roadmaps | Junior → Staff Engineer, freelance, Laravel specialist |

## Projects

- **Beginner:** Portfolio (HTML/CSS static site)
- **Beginner:** System Dashboard CLI (system metrics dashboard)
- **Intermediate:** HTTP Inspector (HTTP request/response inspector)
- **Intermediate:** File Organizer (file sorting/organization tool)
- **Professional:** Markdown Converter (Markdown to HTML converter)

## Prerequisites

- A computer (Windows, macOS, or Linux)
- Ability to install software
- Willingness to learn

## Estimated Time

- **Reading:** 15-20 hours
- **Exercises:** 10-15 hours
- **Projects:** 20-40 hours
