# Level 3: Advanced PHP

**Objective:** Master advanced PHP features — reflection, attributes, generators, iterators, closures, functional programming, and performance optimization.

## Chapters

| # | Chapter | Description |
|---|---------|-------------|
| 1 | Reflection API | Inspecting classes/methods/properties at runtime |
| 2 | Attributes (Annotations) | PHP 8 attributes, custom attributes, reading attributes |
| 3 | Anonymous Classes | Inline class definitions |
| 4 | Closures and Callables | Anonymous functions, closure binding, use() |
| 5 | Functional Programming | array_map, array_filter, array_reduce, currying |
| 6 | Generators | yield, generator delegation, large dataset processing |
| 7 | Iterators | Iterator interface, Iterable, SPL iterators |
| 8 | Streams | Stream wrappers, contexts, filters |
| 9 | SPL Data Structures | SplStack, SplQueue, SplHeap, SplFixedArray |
| 10 | Regular Expressions | PCRE patterns, preg_match, preg_replace, preg_split |
| 11 | Advanced Functions | Variable functions, call_user_func, arrow functions |
| 12 | Late Static Binding | static:: vs self::, get_called_class() |
| 13 | Type System Deep Dive | Covariance, contravariance, intersection types |
| 14 | Memory Management | Reference counting, garbage collection, circular references |
| 15 | Performance Optimization | Profiling, OPcache tuning, JIT compiler |
| 16 | Error Handling Advanced | Throwable interface, error suppression |
| 17 | Output Buffering Advanced | Nested buffers, callbacks, compression |
| 18 | Project: PHP Debugger | Custom debugging and profiling tool |

## Prerequisites

- Level 2 completed
- Strong OOP understanding
- Comfortable with PHP 8.x features

## Projects

- **Mini:** Custom Attribute-based Router
- **Intermediate:** Reflection-based Dependency Injector
- **Professional:** PHP Debugger and Profiler
