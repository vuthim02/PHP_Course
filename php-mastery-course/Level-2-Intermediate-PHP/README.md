# Level 2: Intermediate PHP

**Objective:** Master object-oriented programming, design patterns, database interaction, testing, authentication, and build complex applications.

## Chapters

| # | Chapter | Description |
|---|---------|-------------|
| 1 | OOP Fundamentals | Classes, objects, properties, methods, `$this` |
| 2 | Constructors and Destructors | `__construct`, `__destruct`, constructor promotion |
| 3 | Inheritance | `extends`, `parent::`, `final`, `abstract` |
| 4 | Traits and Interfaces | Traits, interfaces, multiple implementation, resolution |
| 5 | Polymorphism | Method overriding, abstract classes, type variance |
| 6 | Design Patterns — Creational | Singleton, Factory, Builder, Prototype |
| 7 | Design Patterns — Structural | Adapter, Decorator, Facade, Proxy |
| 8 | Design Patterns — Behavioral | Strategy, Observer, Chain of Responsibility, Command |
| 9 | Error Handling and Exceptions | Custom exceptions, try-catch-finally, SPL exceptions |
| 10 | Autoloading | `spl_autoload_register`, PSR-4 |
| 11 | Working with Databases (PDO) | Connections, prepared statements, transactions |
| 12 | MySQL and MariaDB | Schema design, JOINs, indexes, migrations |
| 13 | SQL Injection Prevention | Prepared statements, defense in depth, whitelisting |
| 14 | Composer and Autoloading | Composer setup, PSR-4, dependency management |
| 15 | Dependency Injection | Constructor injection, DI containers, DIP |
| 16 | Namespaces | Organizing code, `use` statements, aliases |
| 17 | PHP Configuration and Performance | php.ini, OPcache, JIT, profiling |
| 18 | Caching in PHP | File cache, Redis, APCu, cache invalidation |
| 19 | File Uploads and Processing | Secure uploads, validation, image processing |
| 20 | Working with APIs (cURL, Guzzle) | HTTP requests, retries, API clients |
| 21 | Testing with PHPUnit | Unit tests, data providers, mocking |
| 22 | Authentication Systems | Password hashing, JWT, session auth, middleware |
| 23 | Authorization (RBAC) | Roles, permissions, policies, ownership checks |
| 24 | MVC Architecture in Depth | Router, controllers, models, views from scratch |
| 25 | Project: Blog CMS from Scratch | Full CMS with auth, posts, comments, admin |

## Prerequisites

- Level 1 completed
- Comfortable writing PHP scripts
- Basic SQL knowledge

## Projects

- **Mini:** PDO Database Repository
- **Intermediate:** REST API Client
- **Professional:** Blog CMS with Admin Panel
- **Enterprise:** Auth and RBAC System
